# 캡처·승인 화면 가독성 개선

## 구현

- 권한 설정의 24개 기능을 8개 그룹과 공통 한국어 이름·설명으로 표시.
- 승인창은 짧은 질문 → 대상 → 원본·대상 경로 → 작업별 주의사항 → 취소·실행 버튼 순서로 표시.
- Rust에 보관한 실행 대기 항목에서 승인 표시 정보를 생성. 앱·파일 열기는 Rust 대상 조회 완료 전 실행 버튼 비활성화.
- 경로 축약은 표시용으로만 적용. 전체 경로 펼치기·키보드 조작·원본 경로 복사 제공.
- 복사·이동 충돌창은 원본과 대상을 분리하고 다른 이름 지정·확장자 확인 흐름 유지.
- 캡처 선택·결과와 승인 버튼에 줄바꿈 방지 적용. 좁은 화면에서는 버튼 전체를 다음 행으로 배치.
- 내부 도구 ID·API·저장값·권한 정책·일회성 승인·파일 상태 재검증은 변경하지 않음.

## 검증

- TypeScript 검사, 프런트엔드 빌드 및 운영 빌드의 개발 테스트 패널 제외 검사 통과.
- Cargo check 통과. Rust 승인 관련 테스트 3개 통과.
- Native 안전성·입력창 Playwright 테스트 26개 통과.
- 최종 버튼 문구 변경 후 다른 이름·확장자 관련 테스트 5개 추가 실행 통과.
- 실제 브라우저 렌더링에서 짧은 이름, 긴 한글·영문 이름, 공백·깊은 경로, 600×520 크기의 승인·충돌·모니터 선택·캡처 결과 화면 확인.
- 전체 경로 키보드 펼치기, 복사 값과 원본 일치, 실행 인자 보존 확인.

## 검증 범위와 남은 확인

- 브라우저 테스트의 Native 호출은 모의 응답 사용. 이번 UI 변경 검증을 실제 Windows 파일 작업·화면 캡처 성공으로 간주하지 않음.
- Rust 변경 반영에는 개발 앱 재시작 필요. 실제 앱에서 캡처·파일 승인 화면을 추가 확인할 수 있음.
- 당시 app.focus 설명은 일반 크기로 복원 후 앞으로 가져오는 동작에 맞췄음. 2026-10-19 포커스 공통 함수 변경으로 최소화 창만 복원하고 일반·최대화 상태를 유지하도록 구현·설명을 함께 갱신함.
- 커밋·푸시·운영 배포·Release 변경 없음.
