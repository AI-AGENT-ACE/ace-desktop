# TTS 연결 보완

- 기존 인증 API `/voice/tts` → AI `/tts` WAV 연결과 서버 저장 설정 `ttsEnabled` 재사용.
- 설정 이름을 `TTS 사용하기`로 명확히 표시. 미리 듣기·재생 중지 추가. 설정 끄기 성공 시 재생과 대기 요청 중단.
- Orb 답변은 메인 창에 재생 요청을 전달하고 메인 창의 인증 세션·설정을 사용. 새 녹음과 Orb 닫기는 재생 중지 요청. 기존 채팅 재생 경로 유지.
- HTML/Markdown 표시 기호를 정리하고 기존 최대 3,000자 제한 유지. Windows 음소거·출력 장치를 임의 변경하지 않음.
- `/agent/voice` 응답의 Base64 음성은 이번 경로에서 재생하지 않음. 별도 `/tts` 경로로 통일하므로 두 음원을 중복 재생하지 않음. AI가 자체적으로 음성을 생성하는 비용이나 앞선 agent_voice 시간 초과 문제를 해결한 것은 아님.
- 모의 TTS 3개·Orb 회귀 23개, 타입 검사·프론트 빌드 통과. 배포 산출물 Native 테스트 패널 제외 유지. 기존 번들 크기 경고 유지. 실제 스피커 청취와 음성 재인식 방지 실기기 시험은 대기.
- 사용자 확인: 개발 앱 재시작 → 설정 TTS 켜기 → 미리 듣기 → 중지 → 일반 채팅·Orb 답변 청취 → TTS 끄고 새 답변에서 소리 없음 확인. 녹음 재시작 시 이전 답변 재생 중단 확인.
- 커밋·푸시·배포 및 DB migration 없음.
- 실제 설정된 AI `/tts`에 공개 테스트 문장 전송: HTTP 200, audio/wav, 218,924바이트, RIFF/WAVE 헤더 확인. 오디오 파일은 저장하거나 재생하지 않음. 이 결과는 AI 직접 HTTP 검증이며 설치 앱·실제 스피커 청취 통과와 구분.
