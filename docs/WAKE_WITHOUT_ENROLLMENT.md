# 녹음 없는 음성 호출 실험

설정에서 음성 호출을 켜고 “ACE”라고 부른다. 첫 실행의 필수 등록 화면은 제거했다. 마이크 대기는 사용자가 켠 뒤 시작하며, 끄기 설정은 재시작 후에도 유지한다. 인식이 부족할 때만 **내 목소리에 맞게 보정 (선택)**을 사용한다.

이미 등록한 사용자는 기존 개인 보정을 유지한다. **기본 호출로 전환**하면 녹음 없이 기본 모델을 사용하고, **저장된 개인 보정 사용**으로 돌아갈 수 있다. 개인 모델 파일은 덮어쓰거나 지우지 않는다.

## 개발용 기본 모델

현재 실험은 이 PC의 등록 모델을 `.local/default-wake.rpw`에 복사해 사용한다. 원본 WAV는 복사하지 않는다. 이 파일은 Git에서 제외되며 debug 빌드에서만 자동 포함된다. `npm run tauri dev`로 다시 빌드해야 기본 모델이 반영된다.

일반 release 빌드는 이 개인 모델을 자동으로 포함하지 않는다. 배포 허가와 출처를 확인한 공용 모델이 준비되면 빌드 시 `ACE_DEFAULT_WAKE_MODEL`을 해당 `.rpw` 경로로 지정한다. 지정한 파일이 없으면 빌드는 실패한다. 실제 모델 형식과 엔진 등록은 Rust 테스트에서 검증한다. 기본 모델이 없는 빌드에서는 기존 개인 보정을 사용할 수 있지만 새 사용자의 녹음 없는 호출은 사용할 수 없다.

이 변경은 공용 모델을 학습한 것이 아니다. 친구와 본인의 호출 두 번 성공은 가능성을 확인한 사례이며, 다양한 화자·거리·소음에서의 인식률과 일반 대화 중 오탐률은 아직 측정하지 않았다.

## 확인 순서

1. 개발 앱을 재시작하고 설정에서 **기본 호출로 전환**을 누른다.
2. 음성 호출을 켜고 새 녹음 없이 여러 거리에서 호출한다.
3. 다른 화자의 호출, 일반 대화와 무음에서 불필요하게 오브가 뜨는지도 확인한다.
4. 비교가 필요하면 **저장된 개인 보정 사용**으로 돌아간다.

자동 검사: Rust 모델 선택·이전 설정 호환·모델 누락·엔진 등록 검사, `node --experimental-vm-modules scripts/test-wake-default.mjs`, 기존 등록/음성/오브 회귀 검사. 실제 마이크 인식률 검사를 대신하지 않는다.
