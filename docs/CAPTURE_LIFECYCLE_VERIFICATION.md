# 캡처 임시 파일 수명 검증

기록일: 2026-10-19. 검증 커밋: 미기록(기존 로컬 변경 포함). 운영·설치 앱 검증이 아님.

## 사용자 수동 결과

- 메모장 후속 시험: 단일 창 선택 생략, 정확한 대상 승인, 포커스 전환, 저장 확인창에서 취소 후 같은 창·문장 보존 통과. 정확한 시험 일시·커밋 미기록.
- 기존 전체/영역 캡처·결과 확인·사용자 저장 통과는 유지. 이번 파일 수명 자동 검증과 구분.

## 실제 Windows 파일·ACE 초기화 경로 검증

- 개인 화면 대신 테스트가 생성한 단색 Windows 창의 32×24 픽셀만 공통 Rust 캡처 함수로 PNG 생성. 픽셀 값·PNG 크기를 검사한 GUI 테스트 1개 통과. 화면 내용은 로그에 출력하지 않음.
- 기존 실행 중인 개발 앱 때문에 기본 실행 파일 교체가 실패하여 별도 테스트 실행 파일 사용. 임시 Cargo example은 `ace_desktop_lib::run()`만 호출하며 실제 Tauri 초기화·`capture_files::start()`를 그대로 실행함. 일반 앱 식별자 대신 `com.ace.capture-verification`을 빌드 설정으로 지정해 캐시·WebView 데이터를 격리함. 설치 앱이나 채팅→승인→저장 버튼 전체 경로 검증은 아님.
- 운영 TTL 3,600초와 정리 주기 60초는 변경하지 않음. 테스트 PNG의 JSON 메타데이터에만 과거 만료 시각 또는 현재+3,600초를 지정함.
- 별도 저장 사본은 `.local/capture-lifecycle/user-saved-copy.png`에 파일 복사로 생성함. 저장 버튼 IPC 자체는 이번 재시작 시험에서 실행하지 않았으며 기존 사용자 수동 저장 결과와 구분함.
- 이번에 시작한 테스트 PID 53228의 실행 파일 경로를 검사한 뒤 강제 종료. 재시작 직전 만료 파일이 남아 있음을 확인하고 PID 60264로 재시작함. 기존 ACE·메모장·개인 파일은 종료/삭제하지 않음.
- 재시작 직후 만료 PNG와 JSON 삭제, 만료 전 PNG 보존 확인. 저장 사본과 만료 전 PNG는 원본 SHA-256과 일치함.
- 재시작 이후 새 만료 fixture를 추가하여 주기 정리 검증: 49초 시점에는 남아 있었고 81초 시점에는 PNG·JSON 삭제 확인. 만료 전 PNG와 저장 사본 유지·동일 SHA-256 확인. `.local/capture-lifecycle/restart-result.json`, `periodic-result.json`은 로컬 실행 증거이며 비밀값이나 이미지 내용 없음.

## 자동 테스트

- `cargo test --manifest-path src-tauri/Cargo.toml capture_files::tests -- --nocapture`: 2개 통과.
- 추가 테스트는 격리된 실제 파일 시스템에 유효 PNG와 JSON을 작성한 뒤 공통 `clean` 함수를 실행함. 만료 경계, 만료 전 보호, 활성 lease 보호, lease가 사라진 이후 정리, 분리된 사용자 사본 바이트 보존 확인.
- 활성 lease 보호는 Rust 상태를 직접 구성한 자동 테스트임. 실제 WebView 미리보기/업로드를 1시간 유지한 시험은 아님. 빈 lease 맵은 재시작 상태를 모형화한 것이며, 위 실제 프로세스 재시작 증거와 별도로 분류함.
- `native_region_capture_omits_hidden_selector_and_writes_valid_png -- --ignored --nocapture`: 실제 Windows GUI 테스트 1개 통과. 테스트에만 선택적 PNG fixture 보존 기능을 추가함. 제품 실행 설정·만료 정책·승인/권한은 변경하지 않음.

## 남은 확인

- 실제 미리보기/업로드 사용 중 만료 경계 보호: 위 Rust 자동 테스트는 통과했지만 전체 UI에서의 장시간 보호는 별도 미검증.
- 필요 시 개인 화면이 없는 테스트 영역을 캡처하고 결과를 사용 중인 상태로 유지 → 1시간 경과 후 다음 정리 주기까지 대기 → 이미지가 계속 열리는지 확인 → 사용 종료 후 임시 파일 정리 확인. 사용자 저장 사본은 별도 위치에 남아야 함. 기존 개인 캡처 메타데이터를 수정하지 말 것.
- 다중 모니터·음성·새 PC·Release·설치 업데이트는 이 결과에 포함하지 않음. 통과한 일반 캡처와 메모장 시험은 관련 변경 없이 반복하지 않음.
