# Orb 녹음 COM 초기화 보완

- 사용자 보고: 메인 화면 음성 입력 클릭 후 `Failed to get audio client`, HRESULT -2147417850(0x80010106, RPC_E_CHANGED_MODE).
- 로컬 CPAL 0.18.2 소스 확인: 기본 COM 초기화 STA, 기본 입력 장치는 ActivateAudioInterfaceAsync 경로 사용. Orb의 전용 녹음 스레드는 기존에 COM 방식 지정이 없었음. 실제 오류 발생 스택은 확보하지 않았으므로 동일 오류의 해결 여부는 재시험 필요.
- audio_input의 녹음/음량 모니터링 전용 스레드에서 CPAL보다 먼저 MTA 초기화. 오디오 객체가 해제된 뒤 같은 스레드에서 CoUninitialize. UI 스레드의 COM 방식·장치 선택·사용자 설정은 변경하지 않음. 초기화 실패를 무시하지 않음.
- cargo check 통과. Windows COM 단위 시험은 마이크를 열거나 녹음하지 않고 전용 스레드의 MTA 및 해제만 확인. 실제 Orb 녹음 성공과 구분.
- 사용자 재시험: 개발 앱을 완전히 종료하고 npm run tauri dev로 재실행 → 메인 화면 음성 입력 → 듣기 표시 확인 → 테스트 문장 발화 → 종료 후 다시 클릭. 동일 오류 재발·마이크 입력·재시작 없이 두 번째 녹음 가능 여부 확인.
- 커밋·푸시·배포 없음. Wake Word·개인 모델 녹음 경로 전체를 재검증한 것으로 처리하지 않음.
