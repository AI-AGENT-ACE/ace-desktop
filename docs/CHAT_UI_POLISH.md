# 채팅 UI 후속 수정 — 2026-10-10

앞선 AI·채팅·Orb 작업의 PR과 분리한 `fix/chat-ui-polish` 작업이다. 이 문서와 새 UI 수정은 아직 커밋하거나 push하지 않았다.

## 변경

- 생각 중 표시 아래의 “답변을 준비하고 있어요. 원하면 언제든 멈출 수 있어요.” 문구를 삭제했다.
- AI 응답 하단을 `응답 복사 | 응답 완료`로 구분했다.
- 사용자 메시지에 마우스를 올리면 말풍선 바로 아래 복사 버튼이 나타난다. 키보드 포커스와 터치 환경에서도 사용할 수 있다. 버튼 영역을 미리 확보하고 투명도만 바꾸므로 표시할 때 말풍선이나 다음 메시지가 움직이지 않는다.
- 아래로 이동 화살표는 현재 화면이 맨 아래에서 100px 이상 위에 있을 때만 표시한다. 스크롤 영역 밖에 겹쳐 배치해 버튼 자체가 스크롤 높이를 늘리지 않는다.
- TOOL 역할의 내부 실행 기록은 화면에서 제외했다. 서버 저장·도구 결과 전달은 유지한다. 입력창 위의 실행 중/성공 배너도 숨기고, 실패·거부 안내는 남겼다.
- 메인 채팅의 승인은 앱 오른쪽 위, 타이틀바 아래의 별도 선택창에서 처리한다. `허용 / 취소`만 표시하며 Escape도 취소한다. 클릭 중 중복 처리는 기존 실행 잠금으로 막는다.
- 음성 명령의 승인은 기존 Orb에서 처리한다. 긍정·부정 버튼은 번호 없이 `네 / 아니오`로 표시한다. 파일처럼 실제 여러 후보 중 고르는 경우에는 번호와 후보 이름을 유지한다.

- 승인창의 위치(상단 52px), 초기 취소 포커스, 승인 전 미실행, 승인 후 한 번 실행, 성공 배너 없음 확인. API는 모의 응답을 사용하며 실제 앱 실행을 재검증한 것은 아니다.

## Orb 청취 상태 제안

청취 상태 자체의 새 디자인은 아직 적용하지 않았다. 요청대로 다음 방안을 제안한다.

| 실제 상태 | 표시 |
| --- | --- |
| 마이크 녹음 활성 | 마이크 아이콘 + 고정된 `듣는 중` 표시, 실제 입력 음량에 반응하는 작은 막대 |
| 녹음 종료 후 STT/AI 처리 | 마이크 반응을 멈추고 `처리 중` 표시 |
| 승인 대기이며 마이크 활성 | `선택 듣는 중` 표시와 선택 버튼 |
| 마이크 시작 실패/중지 | `마이크 꺼짐` 표시. 승인 버튼 클릭은 유지 |

색상만으로 구분하지 않고 문구·아이콘을 함께 사용한다. 파형은 장식용 반복 애니메이션 대신 실제 `recording`과 `audioLevel`에 연결하는 편이 “지금 내 목소리를 듣고 있는지”를 분명히 전달한다.
