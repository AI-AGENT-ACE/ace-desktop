# ACE 구현 단계와 현재 동작

이 문서는 기존 `main`에 포함된 네이티브 구현과 이후 인증·메인 UI 변경을 함께 정리한다. Rust와 Tauri 설정은 기존 구현을 유지한다.

## 1. NestJS API 기반

별도 `ace-backend` 저장소가 인증, 사용자 설정, 대화·메시지, 휴지통, Agent 호출, 실행 로그를 담당한다. PostgreSQL과 Prisma를 사용하며 API 호출에는 사용자 소유권 검사를 적용한다. 개발 환경 값은 각 저장소의 `.env.example`을 참고해 로컬 `.env`에 설정한다.

## 2. 가입 정책과 DB 초기화

비밀번호는 8~128자이며 신규 가입은 영문·숫자·ASCII 기호를 각각 포함해야 한다. 로그인은 기존 계정 호환을 위해 조합 조건을 추가하지 않는다. 프론트 입력 검증과 백엔드 DTO 검증을 함께 적용한다.

`npm run start:dev`는 Prisma 생성과 기존 마이그레이션 적용 후 서버를 시작한다. 회원가입 500의 원인은 연결된 DB에 User 테이블이 없던 상태였다. 스키마 누락은 503으로 구분하며 헬스 체크에서 User와 AuthSession 테이블도 조회한다. 자세한 분석은 백엔드의 `docs/REGISTRATION_500_FIX.md`에 있다.

## 3. React 인증 진입

`features/auth`는 인증 상태 훅, 레이아웃, 입력 폼을 분리한다. 저장된 토큰 확인 중에는 로딩 화면을 표시하고 메인 API 호출을 시작하지 않는다. 가입 성공 시 메인으로 진입하며 로그아웃 시 사용자별 화면 상태를 제거한다.

Edge/WebView2 기본 비밀번호 표시 버튼을 숨겨 커스텀 버튼과 겹치지 않게 한다. 토큰은 sessionStorage에 저장하므로 트레이 숨김·복원에서는 유지되지만 앱 프로세스를 종료하면 다시 로그인한다. 상세 내용은 [인증 UI 문서](AUTH_UI_AND_FLOW.md)를 참고한다.

## 4. 메인 화면과 채팅 흐름

- 새 채팅은 빈 화면만 열고 첫 메시지를 보낼 때 대화방을 생성한다. 버튼의 보조 문구와 접힌 사이드바의 추가 채팅 아이콘을 제거했다.
- 대화 이름은 현재 기본 `새 대화`이며 목록 메뉴에서 변경한다. AI 자동 제목 생성은 구현하지 않았다.
- 홈의 날씨 카드는 `오늘 날씨 알려줘`를 전송하고 환경 설정 카드는 설정 모달을 연다. 로고는 기본 1080×720 창에서 잘리지 않게 배치한다.
- 설정과 휴지통은 사용자 프로필 메뉴에서 연다. 화면 테마는 설정에서 변경한다.
- 권한 설정은 펼침 메뉴 안에서 항상 허용 / 확인 / 항상 확인 중 하나를 선택한다. 서버가 강제하는 실행 확인 조건은 유지한다. 저장 실패 시 이전 선택으로 돌아간다.
- 사이드바는 250ms 동안 부드럽게 열고 닫는다. 닫힌 내용은 포커스와 접근성 트리에서 제외하고 운영체제의 동작 줄이기 설정을 따른다.
- 채팅과 검색 입력의 외곽선 대신 배경·테두리·커서 색으로 포커스를 표시한다.
- 플러스 메뉴는 파일 추가를 제공한다. TXT·MD·CSV·JSON 파일을 UTF-8로 읽어 메시지와 함께 전송한다. 파일은 64KB·15,000자 이하, 전체 메시지는 20,000자 이하이다. 이미지·PDF·바이너리 업로드와 독립적인 파일 저장 API는 제공하지 않는다.

## 5. Rust 네이티브 실행 책임

`src-tauri/src/lib.rs`는 창 숨김, 트레이 열기·종료, IPC 등록과 창 닫기 요청을 담당한다. X 버튼과 Alt+F4는 창을 숨기며 프로세스를 유지한다. 트레이의 ACE 열기 또는 좌클릭은 숨겨진 창을 복원하고 ACE 종료는 프로세스를 종료한다.

`local_commands.rs`는 호출 창과 인자를 다시 검증한다. 시스템 상태 조회는 허용하고, 메모장·계산기 실행/종료는 승인이 필요하다. 임의 명령과 파일 작업은 차단한다. 서버의 권한 선택만으로 Rust 정책을 우회할 수 없다.

`voice_overlay.rs`는 별도 `voice` 창을 생성하고 음성 명령을 main으로 일시 전달한다. 해당 창에만 항상 위 표시를 적용한다. 실제 STT 연결은 아직 제공하지 않는다.

`taskbar.rs`는 Windows 창의 AppUserModelID, 재실행 이름·명령·아이콘을 설정한다. 투명 ACE 아이콘은 창·트레이·번들에 사용한다. 아이콘 리소스와 Windows 캐시 관련 내용은 [아이콘 문서](APP_ICONS.md)를 참고한다.

## 6. Tauri 창과 보안 설정

`src-tauri/tauri.conf.json`은 이름 ACE, 식별자 `com.ace.desktop`, 중앙 배치, 기본 1080×720, 최소 600×500, 시스템 타이틀바 숨김을 설정한다. `capabilities/default.json`은 main 창의 최소화, 최대화 전환, 닫기, 드래그를 허용한다.

`src/lib/windowAdapter.ts`에서 최소화와 최대화·복원을 즉시 호출한다. 캡처 이미지를 늘리거나 작업표시줄로 빨려 들어가는 효과는 사용하지 않는다. X 버튼의 기존 숨김 효과와 테마 300ms 색상 전환은 유지한다. 상세 내용은 [창 전환 문서](UI_TRANSITIONS.md)에 있다.

기본 CSP의 API 연결 주소는 `http://127.0.0.1:3001`이다. `npm run tauri dev/build`는 `scripts/tauri.mjs`에서 `VITE_API_BASE_URL`의 Origin을 CSP에 반영한다. 직접 Tauri CLI를 실행할 때는 CSP 허용 주소도 확인해야 한다. Rust·Tauri 변경을 반영하려면 트레이에서 완전히 종료한 후 다시 실행한다.

## 검증과 GitHub 반영

데스크톱은 `npm run build`와 `npm run test:e2e`, 인증 UI만 검사할 때는 `npm run test:auth`를 사용한다. Rust 검사는 `src-tauri`에서 `cargo test --offline`을 실행한다. 백엔드는 빌드·린트·단위 테스트와 별도 테스트 DB를 사용하는 API E2E를 실행한다.

변경은 백엔드 비밀번호 정책 → 백엔드 DB 초기화·오류 처리 → 데스크톱 인증 UI → 데스크톱 메인 UI·채팅 → 네이티브 동작 문서 순으로 기능 브랜치에서 PR을 만들고 main으로 병합한다. 기존 main의 네이티브 코드를 다시 추가하는 변경은 만들지 않는다.

`.env`, node_modules, 빌드 결과, Rust target, 테스트 출력, 로컬 DB와 개인 키는 Git에서 제외한다. `.env.example`만 설정 예제로 관리한다.
