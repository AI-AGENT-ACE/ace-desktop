# ACE v0.2.0

- 개인 ACE 호출어 모델을 기본 리소스로 포함하여 별도 등록 없이 호출 가능하도록 구성
- 기본 모델은 개인 목소리 기반이며 여러 사람 대상 인식률·오탐 평가는 대기 상태. 인식이 어려우면 설정에서 개인 목소리 등록 사용
- 기본 모델과 개인 등록 모델의 저장 위치를 분리하여 업데이트 시 개인 모델 보존
- 앱 창 선택·정상 종료, 파일 작업 승인·덮어쓰기·휴지통 이동, 화면 캡처 흐름 개선
- 채팅 및 Orb Markdown 표시, TTS 설정, 프로필 편집 개선
- 개발용 Native 테스트 패널 제거 및 운영 빌드 제외 검사 적용
- 서명 검증을 사용하는 업데이트 확인·다운로드 지원
- Windows 게시자 코드 서명은 미적용. 업데이트 서명과 별개
- 새 PC 설치·실제 업데이트·다중 사용자 호출어 평가는 별도 확인 필요
