# feat(voice): 음성 세션 복구와 로컬 포트폴리오 명령 지원

대상: `fix/wake-native-enrollment` ← `feat/local-voice-portfolio` (Draft)

## 사건

로그인했는데 별도 음성 창에서 로그인 요청이 표시되고, 발화 후 녹음이 끝나지 않았다. AI 서버가 연결되지 않은 환경에서는 포트폴리오 PDF 열기 명령도 처리할 수 없었다.

## 원인 분석

메인 창과 음성 창은 별도 WebView여서 인증 메모리를 자동으로 공유하지 않는다. 녹음 종료 판단과 전달 실패 처리가 부족했다. 기존 음성 요청은 AI 서버에 의존했다.

## 해결 방안

- 메인 창의 현재 인증 상태를 요청하는 브리지와 갱신 흐름을 추가했다.
- 초기 대기, 발화 판정, 발화 후 1.5초 무음, 30초 상한을 적용했다.
- 임시 WAV를 한국어 로컬 Whisper로 인식하는 포트폴리오 모드를 추가했다. 설치 스크립트와 검증 예제를 제공한다.
- 명시적인 열기 명령일 때만 바탕화면의 `김환성_포트폴리오.pdf`를 기존 네이티브 실행 경로로 연다.
- 부정문/다른 명령/명령 인용을 임의의 파일 열기로 바꾸지 않는다. 음성과 모델은 Git에 포함하지 않는다.

## 결과

기존 검증에서 Rust 46개 통과, 7개 제외, 음성 회귀 4개 통과 및 TypeScript/Vite 검사를 통과했다. 회귀 범위는 별도 창의 로그인·토큰 갱신·동시 요청·로그아웃, 무음 종료, 허용된 명령 분류다.

사용자 후속 로그에서는 녹음 종료와 로컬 STT까지 진행됐으나 “포트폴리오예요”로 인식되어 실행 의도가 없는 문장으로 거부됐다. 해당 발화의 실제 PDF 열기 성공이나 인식 정확도 개선은 주장하지 않는다. 오인식 뒤 재시도와 실제 완료 후 종료는 후속 오브 PR에서 처리한다. AI 서버 연동은 이번 범위에서 보류한다.
